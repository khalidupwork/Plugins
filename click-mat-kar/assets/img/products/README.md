# Product images — drop-in art for the shop games

Put one image per product in this folder, named exactly after the product id. The theme detects files automatically and shows them instead of the emoji; any product without a file keeps its emoji. No code changes needed.

## Spec
- **File name:** `{product-id}.webp` (also accepts .png / .jpg / .avif), e.g. `gucchi-bag.webp`
- **Size:** 600 × 600 px, square, **transparent background**, subject centred with ~10% padding
- **Weight:** under 60 KB each (WebP quality 75–80). 90 images ≈ 4 MB total, loaded lazily
- **Style (match the brand moodboard):** 3D clay/vinyl "sticker" look, chunky shapes, bold black outline, soft drop shadow, bright brand colours (lime #D7FF3F, pink #FF72B6, lavender #B9A7FF, orange #FF9A3D, blue #65C7FF, mint #65DFA4)
- **Legal:** parody only. Use the parody name on the product (GUCCHI, ROLAX, LAMBO-GHANTA…). **Never** copy real brand photos or real logos/monograms; draw original shapes.

## Shared prompt prefix (AI image tools)
> 3D clay sticker illustration, playful, chunky, bold 4px black outline, soft shadow, bright saturated colours, isolated on transparent background, centred, product shot, no real brand logos, no text except the label described:
