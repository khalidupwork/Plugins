# MyRepairCo website – client brief

## Concept
- Dispatch background-verified home service technicians for same-day small jobs, with real-time tracking (like DoorDash / Uber).
- **No video chat.** Frontdoor.com is a reference for how the site shows booking from a phone, not for its video-chat product.

## Layout
- Copy the **MyPaintingCo** (mypaintingco.com) layout for MyRepairCo.
- Bring in Frontdoor's sections as you scroll: phone images, "how it works" steps, and how to dispatch a tech.
- Frontdoor's "A one-stop app for home repair and maintenance needs" section becomes **our list of home services**.

## Branding
- Change the theme from blue to **red**, matching the red MyRepairCo logo.
- Make all buttons red instead of blue.
- Redo the MyRepairCo logo so it looks like the MyPaintingCo logo: mascot, "my" inside a house outline, "Repair Co.", and the domain underneath.
