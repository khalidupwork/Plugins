=== MyRepairCo Site Kit ===
Requires Plugins: elementor
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0

Sets up the MyRepairCo red theme for Elementor Pro and creates the Home page, Header and Footer.
The layout follows MyPaintingCo, and the booking and live-tracking sections follow Frontdoor.

== What it does ==

Tools > MyRepairCo Site Kit has two buttons:

1. Apply global styles
   * Global Colors: Brand Red #C62828 (primary), Dark #1B1B1F (secondary), Body Text #4A4A4A,
     Red Hover #A31F1F (accent), Light Background #F7F3EF, White, Blush #F9D9D5.
   * Global Fonts: Montserrat for headings and buttons, Open Sans for body text.
   * Theme Style: H1-H6, body, links, buttons (red, with darker red on hover) and form fields. Container width is 1200px.
   * Custom CSS helper classes (Site Settings > Custom CSS): mrc-card, mrc-on-dark, mrc-eyebrow,
     mrc-btn-light, mrc-btn-outline-light, mrc-photo, mrc-narrow, mrc-brand-col, mrc-others-col.
   * Turns on "Disable Default Colors" and "Disable Default Fonts", so widgets take their styling from Theme Style.
   Your current Site Settings are backed up first. "Restore previous global styles" puts them back.

2. Create page, header & footer (everything is created as a DRAFT)
   * Page "MyRepairCo Home" (Elementor Full Width): hero, same-day strip, Contact us today,
     Why Choose Us (6 cards + counters), How It Works (phone), Live tracking (phone + map),
     Services grid, MyRepairCo vs Others, Recent Projects, About, Testimonials, CTA band,
     Hiring Technicians, Blog.
   * Theme Builder Header and Footer, set to display on the Entire Site (they take effect once published).
   * A menu called "MyRepairCo Main".
   * Uploads the hero photo, the red logo, the original blue logo, the mascot and the two phone illustrations to the Media Library.
     To use the blue logo instead, swap the image in the Header and Footer (Media Library: myrepairco-logo-original-blue.png).

All sections use native Elementor containers and widgets. Colors and fonts come from Site Settings.
The page itself only stores layout values (columns, gaps, alignment) and references to the global colors.

== After running it ==

1. Open the drafts in Elementor and replace:
   * the sample testimonials (marked "Sample review") with real reviews,
   * the phone number, email and address if they are still the placeholder values.
2. Publish the Header and Footer (Templates > Theme Builder).
3. Publish the page, then set it as the homepage under Settings > Reading.

== Editing the design ==

The JSON files are generated by dev/build.py. Edit that file and run `python3 dev/build.py`.
To get a rough static preview without WordPress, run `python3 dev/preview.py > dev/out/preview.html`.
